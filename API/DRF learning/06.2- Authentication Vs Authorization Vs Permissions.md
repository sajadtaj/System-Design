این سؤال بسیار مهمی است، چون در DRF و حتی مستندات مختلف این سه واژه گاهی با هم قاطی می‌شوند:

```text
Authentication
Authorization
Permissions
```

---

# تعریف دقیق

## Authentication

پاسخ به سؤال:

```text
شما چه کسی هستید؟
```

مثال:

```text
username = sajad
password = ******
```

یا:

```http
Authorization: Token xxxxx
```

نتیجه:

```python
request.user
```

مشخص می‌شود.

---

## Authorization

پاسخ به سؤال:

```text
شما مجاز به انجام چه کاری هستید؟
```

مثال:

```text
کاربر لاگین کرده است
↓
می‌خواهد کتابی را حذف کند
↓
آیا مجاز است؟
```

این مفهوم کلی Authorization است.

---

## Permissions

در DRF، Permission یکی از مکانیزم‌های پیاده‌سازی Authorization است.

یعنی:

```text
Authorization
    ↓
Permissions
```

---

# رابطه آنها

```text
Authentication
    ↓
User Identified
    ↓
Authorization
    ↓
Permissions
    ↓
Access Granted / Denied
```

---

# مثال واقعی

فرض کنیم API زیر را داریم:

```http
DELETE /api/books/15/
```

مراحل:

### مرحله 1

DRF بررسی می‌کند:

```text
این درخواست متعلق به چه کسی است؟
```

Authentication

نتیجه:

```python
request.user = sajad
```

---

### مرحله 2

بررسی می‌کند:

```text
آیا sajad اجازه حذف کتاب را دارد؟
```

Authorization

---

### مرحله 3

برای پاسخ دادن به این سؤال از:

```python
IsAdminUser
```

یا:

```python
IsOwnerPermission
```

استفاده می‌کند.

این همان Permission است.

---

# تشبیه ساختمان

فرض کنید وارد یک ساختمان اداری می‌شوید.

## Authentication

نگهبان کارت شناسایی شما را بررسی می‌کند.

```text
شما چه کسی هستید؟
```

---

## Authorization

پس از شناسایی بررسی می‌شود:

```text
به کدام طبقات مجاز هستید؟
```

---

## Permission

قوانینی که این دسترسی را تعیین می‌کنند.

مثلاً:

```text
کارمندان:
طبقات 1 تا 3

مدیران:
طبقات 1 تا 10

مدیرعامل:
همه طبقات
```

این قوانین همان Permission هستند.

---

# در DRF

Authorization یک مفهوم است.

Permission پیاده‌سازی آن مفهوم است.

مثلاً:

```python
permission_classes = [
    IsAuthenticated
]
```

یا:

```python
permission_classes = [
    IsAdminUser
]
```

یا:

```python
permission_classes = [
    IsOwnerPermission
]
```

همگی ابزارهای Authorization هستند.
