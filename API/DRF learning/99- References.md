# 99 - References

## هدف

این فایل فهرست منابع رسمی مورد استفاده در کتاب DRF است.

اصل حاکم بر این کتاب:

- اولویت با مستندات رسمی است.
- از منابع منسوخ یا غیررسمی استفاده نمی‌شود مگر با ذکر دلیل.
- در صورت تعارض بین منابع، مستندات رسمی پروژه مرجع اصلی محسوب می‌شوند.
- مثال‌ها و Best Practice ها تا حد امکان بر اساس این منابع تدوین شده‌اند.
